1. Utworz puste repo na github.com (np. worldgradient) i wrzuc tam WSZYSTKIE pliki z tego folderu
   (z ukrytym folderem .github).
2. Wejdz w zakladke Actions -> workflow "build" -> poczekaj az sie skonczy (ok. 3-5 min).
3. Na dole strony przebiegu pobierz artefakt "worldgradient-jar" (zip), w srodku jest worldgradient-1.0.0.jar
   (NIE ten z -sources).
4. Wrzuc jar do mods/ razem z WorldEdit i Fabric API.
Jesli build sie wywali, skopiuj blad z logu i wklej mi go.
